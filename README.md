## 🗄️ Database
- Provider: **Turso (libSQL)**

## 📦 Getting Started
1. Clone this repository:
   ```bash
   git clone <repo_url>
   cd my-app
   ```
2. Copy your `.env.local` with your `DATABASE_URL` and `TURSO_AUTH_TOKEN`.
3. Every time you push to the `main` branch, GitHub Actions will automatically compile and deploy to your live URL!
